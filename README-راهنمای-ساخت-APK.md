# مدیریت تخلیه بار — سورس پروژه

این پروژه یک برنامه React + Vite با رابط فارسی و راست‌چین است که برای بسته‌بندی به APK از Capacitor و GitHub Actions استفاده می‌کند. ساخت APK روی سرور GitHub انجام می‌شود؛ در این محیط APK نهایی ساخته یا روی گوشی آزمایش نشده است.

## ساخت APK فقط با گوشی

1. ZIP را در گوشی دانلود و استخراج کنید.
2. در github.com وارد حساب خود شوید و یک مخزن جدید بسازید.
3. **محتویات داخل پوشه** «مدیریت تخلیه بار روزانه» را در ریشه مخزن بارگذاری کنید. پوشه مخفی `.github/workflows` و فایل `build-apk.yml` باید هم بارگذاری شوند.
4. در مخزن وارد زبانه **Actions** شوید.
5. گردش‌کار **Build Android APK** را انتخاب کنید و روی **Run workflow** بزنید.
6. پس از اتمام موفق، اجرای workflow را باز کنید و از بخش **Artifacts** فایل `load-management-debug-apk` را دانلود کنید.
7. ZIP مربوط به Artifact را در گوشی استخراج کنید و فایل `app-debug.apk` را نصب کنید. ممکن است اندروید اجازه نصب از منبع انتخاب‌شده را درخواست کند.

## اجرای نسخه وب برای توسعه

```bash
npm ci
npm run dev
```

## نکات مهم پیش از استفاده واقعی

- این نسخه فعلی یک **نسخه اولیه قابل توسعه** است، نه پیاده‌سازی کامل همه بندهای شرح نیازمندی.
- ثبت‌ها فعلاً به‌صورت یک رکورد برای هر تاریخ انجام می‌شوند و تعداد سه نوع خودرو در همان رکورد نگهداری می‌شود.
- دستمزدها در این نسخه به‌صورت کلی ذخیره می‌شوند؛ نرخ جداگانه برای هر سال و ماه و ثبت snapshot دستمزد روی هر رکورد هنوز پیاده‌سازی نشده است. بنابراین برای محاسبه قطعی حقوق چندماهه، فعلاً به این نسخه اتکا نکنید.
- هزینه بار و مبلغ دریافتی به‌عنوان فیلدهای مستقل در فرم ثبت هنوز اضافه نشده‌اند.
- داده‌ها در حافظه محلی WebView ذخیره می‌شوند؛ پاک‌کردن داده‌های برنامه یا حذف نصب ممکن است آن‌ها را از بین ببرد. از بخش پشتیبان‌گیری JSON استفاده کنید و فایل پشتیبان را خارج از برنامه نگه دارید.
- گزارش JPG وجود دارد؛ قبل از استفاده عملی، خروجی را روی گوشی خود بررسی کنید.
- گزینه‌های Excel و CSV در رابط گزارش‌ها نمایش داده نمی‌شوند.
- APK باید پس از ساخت GitHub Actions روی دستگاه واقعی نصب و آزمایش شود. اجرای موفق workflow به‌تنهایی جایگزین آزمایش محاسبات و رفتار اندروید نیست.

## فناوری‌ها

- React + TypeScript + Vite
- رابط راست‌چین و تقویم شمسی
- Capacitor Android (در workflow اضافه می‌شود)
- GitHub Actions برای ساخت APK آزمایشی (debug)
